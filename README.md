# DocFlow：基于 RAG 的智能文档问答系统

DocFlow 是一个面向文档编辑、AI 写作和知识库问答的智能文档系统。  
项目基于富文本编辑器能力进行扩展，支持文档编辑、AI 辅助写作、知识库问答、文档搜索和 PDF 导出等功能。

## 项目简介

本项目主要实现了一个类似 Notion 的在线文档编辑平台，用户可以创建和编辑文档，并通过 AI 完成内容总结、润色、扩写、翻译等操作。

同时，系统支持将文档内容同步到知识库，通过 RAG 检索增强的方式，让用户可以围绕已有文档进行智能问答。

## 技术栈

- Next.js
- React
- TypeScript
- Tailwind CSS
- Tiptap / Novel
- Vercel AI SDK
- DeepSeek API
- LangChain.js
- Qdrant / PGVector
- html2canvas
- jsPDF

## 核心功能

- Notion 风格富文本编辑器
- 支持标题、列表、引用、代码块、图片、公式等内容编辑
- Slash 命令快捷插入内容
- 文档自动保存
- AI 写作辅助：总结、润色、扩写、翻译、续写
- RAG 知识库问答
- 文档搜索
- 文档目录和历史记录
- PDF 导出

## 项目亮点

1. 基于 Tiptap 封装富文本编辑器，实现了较完整的文档编辑体验。
2. 接入 AI 能力，支持对选中文本进行总结、润色、扩写和翻译。
3. 通过文档切片、向量化和相似度检索，实现基于文档内容的 RAG 问答。
4. 对编辑内容进行 JSON、HTML、Markdown 和纯文本多格式处理，方便存储、渲染、导出和知识库同步。
5. 使用防抖机制处理文档自动保存，减少频繁请求带来的性能开销。
